# 집핀 리뉴얼 계획 (벤치마킹 반영, 주인 결정과 맞춤)

원본 브리프: docs/benchmark_brief.md. 아래는 주인이 이미 정한 것과 충돌하지 않게 고친 실행판이다.

## 주인 결정 유지 (브리프보다 우선)
- 구역 색은 남색 하나. 4단계 상태는 **남색 안에서** 채움/테두리/점/점선으로만 구분(새 색 추가 안 함, 경고만 주황).
- 지도 오른쪽 위 레이어 버튼 6개 고정·이름표 유지(하나로 합치지 않음). 대신 더 작게.
- 헤더 "집핀 Zippin" 유지. 부제 "서울 재개발 지도"는 폰에서 숨기고 데스크톱만.
- 한 손가락 이동·두 손가락 확대, 로그인 없음, 사업자 정보 없음.

## 실행 단계 (순서대로, 한 번에 한 에이전트)
1. **IA·내비** — 하단 탭 4개(찾기·관심·소식·MY). 헤더 오른쪽 버튼 정리(🔔→소식 탭, ⋯ 삭제, 월간 리포트→MY). MY 화면 신설: 내 조건, 알림 켜고 끄기, 내보내기/옮기기, 데이터 모두 지우기(확인 단계), 도구·가이드, FAQ, 출처·계산 방법, 문의, 약관·개인정보, 버전·기준일. 앱 화면에서 웹 푸터 숨김. 정적 페이지(/z, /gu, /guide, 404)도 같은 하단 탭.
2. **찾기(홈)** — 첫 방문 질문 1개("지금 쓸 수 있는 현금이 얼마예요?" 칩 + 나중에). 예산 카드 한 줄 "내 돈 1억 ▾ → 갈 수 있는 곳 9곳" + 전세/대출 세그먼트. 예산 시트(칩+슬라이더+금액별 막대+"+0.5억이면 N곳 더"). 조건은 URL ?cash=&mode= 와 로컬에 저장. "더 알아보기" 6칸 삭제, 분모 표기 삭제.
3. **지도 핀·시트** — 핀에 "지금 필요한 돈" 가격 알약(상위 40개), 4단계 상태, 관심 구역 노란 테두리, NEW 배지. 줌 11 이하 구 묶음 원 "구로 · 가능 3". 목록 카드 84px(이름·단계 / 구·동·역 도보 / 지금 · 입주까지 / ♡), 스파크라인은 상세로. 정렬 시트.
4. **구역 상세** — 첫 화면에 3숫자(지금 필요한 돈 · 입주까지 현금 · 언제 입주/입주권), 신뢰 한 줄(추정 칩 1개, 근거는 눌러서), 하단 고정 [관심 구역에 추가]. 섹션 고정 탭. "이 숫자가 틀렸어요" 신고(구역 ID 자동 첨부).
5. **카피·용어 통일** — 용어집(내 돈 / 지금 필요한 돈 / 입주까지 현금 / 입주 / 관심 구역 / 갈 수 있는 곳), 1억 미만 만 단위, 닫기/나중에, 면책 1회. qa_consistency에 용어 검사 추가.
6. **앱다운 느낌** — 탭 하이라이트·길게 눌러 선택 끄기, overscroll 방지, 외부 링크 ↗, 시트 손잡이, 설치 권유는 관심 추가/알림 켠 직후에만(닫으면 30일).

각 단계 끝: qa.js + qa_consistency.js 통과 → 배포 → 다음 단계. 마지막에 17차 채점(13개 분야, 채점관 2명).
