## B. 지금 집핀 진단

### 잘하고 있어서 지켜야 할 것
- 홈 맨 위에 "내 현금 1억 → 9곳"과 슬라이더가 있어요. 출발점이 이미 예산이에요.
- 지도 범위 안에 살 수 있는 곳이 없을 때 이렇게 보여 줘요(m-map-list.png). Realtor.com이나 Zillow보다 한 단계 앞선 빈 화면이에요.
  > "이 지도 범위는 최소 3.5억부터 살 수 있어요" [3.6억으로 올려 보기] [서울 전체]
- 알림 시트의 문구와 구성이 좋아요(m-alertsheet.png). "알림 받기 / 나중에", 혜택 4가지를 보여 줘요.
- 신뢰를 주는 장치가 있어요. "실거래 10.16 신고분까지 · 10.18 갱신", "이 숫자 믿어도 될까: 보통 · 표본 17건".
- 404 화면이 친절하고 검색창이 있어요. 오프라인에서 다시 불러와도 서비스워커가 화면을 보여 줘요.
- 앱 설정이 갖춰져 있어요. manifest가 standalone이고, maskable 아이콘과 스크린샷이 있고, viewport-fit=cover예요.
- 소개, 출처·계산 방법, 문의, 약관, 개인정보처리방침 페이지가 모두 200으로 열려요.
- 첫 화면 성능은 DCL 약 1.5초, 리소스 20개, 약 1MB예요.

### 문제

1. **메뉴가 세 군데에 중복돼요.** 헤더의 ⋯, 하단 탭의 "더보기", 홈의 "더 알아보기" 6칸이 같은 메뉴예요. 헤더에도 로고, Zippin, "서울 재개발 지도", 🔔, "월간 리포트", ⋯가 몰려 있어요.
2. **지도 핀이 핵심을 말하지 못해요.** 가능한 구역 9곳만 똑같은 집 아이콘으로 표시하고 가격이 없어요. 구역 폴리곤은 살 수 있든 없든 모두 같은 회색·남색이에요. 확대해도 가격 라벨이 나오지 않아요(m-map-zoom.png). 학교·학원 등 레이어 버튼 6개가 지도의 약 15%를 가려요.
3. **지도에서 목록으로 가면 지도가 사라져요.** "목록 보기"를 누르면 홈 목록으로 스크롤되고 하단 탭도 "홈"으로 바뀌어요. 지도 위에 바텀시트로 뜨는 구조가 아니에요.
4. **상세 화면 첫 화면에서 돈 숫자가 엇갈려요(m-detail.png).**
   - 스크롤 전에 보이는 건 입지 53점, 태그 칩들, 미니 지도, "실거래 1억 6,500만"이에요.
   - 그런데 목록 카드에는 "지금 0.73억"이라고 나와요. 사용자는 0.73억과 1.65억 중 무엇이 맞는지 헷갈려요.
   - 핵심 3숫자(지금 0.73억, 입주까지 현금 5.3억, 입주 15년 넘게)는 두 화면 넘게 스크롤해야 나와요.
5. **화면이 두 제품처럼 보여요.** `/z/…` 구역 페이지와 404 페이지는 웹사이트식 헤더(계산기·월간 리포트·구역별 페이지·가이드·분석)를 쓰고 하단 탭이 없어요(m-zone.png).
6. **같은 개념을 여러 이름으로 불러요.**
   - 돈: 내 현금 / 이 돈이면 / 지금 필요한 돈 / 계산 매수가 / 지금
   - 개수: "가능 3곳 · 지도 42곳", "전세 시세 있는 120곳 중"
   - 저장: 핀 꽂고 알림 받기 / 알림 받기 / 관심 구역
7. **"전세 시세 있는 120곳 중"이 데이터 공백을 드러내요.** 지도에는 구역이 수백 곳인데 분모가 120이라 오히려 신뢰를 떨어뜨려요.
8. **첫 실행 안내가 말풍선 하나뿐이에요.** "끌어서 내 현금을 맞춰 보세요"만 있어요. 무주택·평형 같은 조건은 "조건 더 보기" 안에 숨어 있어요.

### 1-3. 예산 입력 방식

결론: **첫 실행 때 질문 1개를 묻고, 그 뒤로는 프리셋 칩과 슬라이더를 쓰고, 슬라이더 위에 분포를 보여 줘요.**

**첫 실행 (전체 화면 1장, 건너뛸 수 있음)**
- 질문: "지금 바로 쓸 수 있는 현금이 얼마예요?"
- 칩: [5천만] [1억] [2억] [3억] [5억] [7억] [10억+]
- 보조 버튼: "잘 모르겠어요 → 1억으로 둘러보기"
- 다음 화면은 선택이에요: "집 있어요?" [없어요] [1채(팔 거예요)] [1채(유지)] [2채 이상]. 다음 버튼은 "다음", 건너뛰기는 "나중에"로 써요.
- 회원가입은 요구하지 않아요. 저장하거나 알림을 켤 때 처음 요구해요(Compass 방식).

**평소 (예산 시트)**
- 큰 숫자: "1억"
- 프리셋 칩 줄과 슬라이더(0.5~15억, 0.1억 단위)를 둬요.
- 슬라이더 위에 **금액별 가능 구역 수 막대**를 보여 줘요(Airbnb 히스토그램 방식).
- 다음 금액대 안내를 붙여요: "+0.5억이면 12곳 더"
- 버튼: [9곳 보기]

**저장**
- 조건은 URL `?cash=1&mode=jeonse`와 로컬 저장소에 남겨요.
- MY에서 바꿀 수 있고, 다시 들어와도 그대로 유지돼요.

### 1-4. 지도 핀 명세

**라벨**

**상태 4가지 (Realtor.com 방식)**
| 상태 | 조건 | 모양 |

| 가능 | 필요한 돈 ≤ 내 돈 | 남색으로 채움, 흰 글씨, 가격 표시 |

| 멀다 | 20% 넘게 더 필요 | 6px 회색 점, 라벨 없음(Airbnb mini-pin) |

- 구역 폴리곤도 같은 색 체계로 칠해요. 가능은 채움 20%, 모자람은 테두리만, 나머지는 아주 옅게 해요.

**보조 상태**
- 선택한 핀: 짙은 색, 1.15배 확대, 꼬리 표시, 시트의 해당 카드로 자동 스크롤

- 관심 구역: 노란 핀으로 구분(Zillow 비평 반영)

### 1-8. 카피 규칙 (토스식)

**말투**
- 해요체로 써요. 문장 하나에는 숫자 하나만 넣어요.
- 내 돈 관점으로 써요. "4.3억 더 필요해요" (O), "부족액 4.3억" (X)

**버튼**
- 주요 버튼은 "~하기"나 결과를 말하는 문구로 써요. 예: "9곳 보기", "관심 구역에 추가하기"
- 닫는 버튼은 "닫기", 미루는 버튼은 "나중에"로 써요. "취소"는 데이터를 버릴 때만 써요.
- 바텀시트 제목은 한 줄로 써요.

**용어집 (하나로 고정)**
| 쓸 말 | 뜻 |
|---|---|
| 내 돈 | 지금 쓸 수 있는 현금 |
| 지금 필요한 돈 | 계약할 때 드는 현금 |
| 입주까지 현금 | 입주할 때까지 드는 현금의 합 |
| 입주 | 새 아파트에 들어가는 시점 |
| 관심 구역 | 저장한 구역 |
| 갈 수 있는 곳 | 결과 목록 |

- "가능", "살 수 있는", "이 돈이면", "계산 매수가"는 섞어 쓰지 않아요.

**전문용어는 풀어 쓰기 (Zero Jargon)**
- 권리가액 → "내 지분 값"
- 프리미엄 → "웃돈"
- 비례율 → "사업성 비율(i)"
- 처음 나올 때는 원래 용어를 괄호로 한 번 같이 적어요.

**숫자 표기**
- 1억 이상은 소수점 한 자리까지 쓰고 끝의 0은 지워요. 예: `1.6억`
- 1억 미만은 `7,300만`으로 써요. `0.73억`은 쓰지 않아요.
- 숫자는 tabular-nums로 정렬해요.
- 연도는 "2040년쯤"처럼 써요.

**추정 표시**
- 화면마다 `추정` 칩은 한 번만 붙여요. 근거는 칩을 눌렀을 때 보여 줘요.
- 면책 문구는 상세 화면 맨 아래에 한 번만 둬요.

**빈 화면과 오류**
- 원인, 다음 행동 버튼 하나, 대안 하나 순서로 써요.
- 예: "이 범위엔 아직 없어요 · [0.5억 올려 보기] · 서울 전체 보기"

## 2. 루브릭 추가 항목: "앱·홈페이지 완성도"

판정 방법: 항목마다 정해진 화면을 Playwright로 390×844(터치)와 1440×900에서 확인하고, 객관적으로 판단해요.
- **95:** 모두 충족
- **90:** 사소한 예외 1개
- **80:** 핵심은 충족, 예외 2~3개
- **70:** 핵심 결함 있음

### ① 첫 실행과 온보딩
- **95:** 첫 방문 때 1~2문항으로 예산을 받아요(건너뛰기 가능). 이때 회원가입·권한 요청은 0번이에요. 끝나면 결과 화면으로 바로 가고, 다시 방문하면 조건이 유지돼요. 딥링크로 들어온 사용자에게는 온보딩을 생략해요.
- **90:** 온보딩은 있는데 다시 방문했을 때 일부 조건이 초기화돼요.
- **80:** 말풍선이나 코치마크만 있어요. 조건은 숨은 메뉴에서만 바꿀 수 있어요.
- **70:** 안내가 없어요. 첫 화면에서 무엇을 해야 할지 문구가 없어요.

### ② 내비게이션 일관성
- **95:** 하단 탭이 5개 이하예요. 모든 화면(구역 페이지, 가이드, 리포트, 404 포함)이 같은 헤더와 탭을 써요. 같은 목적지로 가는 입구는 2개 이하예요. 지금 있는 탭이 항상 정확히 강조돼요.
- **90:** 정적 페이지 1종만 헤더가 달라요.
- **80:** 메뉴가 3곳 이상에 중복되거나, 다른 화면으로 이동한 뒤 탭 강조가 틀려요.
- **70:** 웹사이트 헤더와 앱 탭 구조가 섞여 있어요.

### ③ 뒤로 가기와 상태 보존
- **95:** 기기·브라우저의 뒤로 가기가 항상 직전 화면으로 가요. 시트는 닫히고, 상세에서 목록으로 돌아오면 스크롤 위치와 시트 높이가 그대로예요. 모든 상세 화면은 고유 URL(딥링크)이 있어요. 첫 화면에서 뒤로 가기를 눌러도 앱 밖으로 튕기지 않아요(또는 의도한 동작이에요). 시트 위에 시트가 겹치지 않아요.
- **90:** 스크롤 위치만 가끔 초기화돼요.
- **80:** 일부 시트를 뒤로 가기로 닫을 수 없어요.
- **70:** 뒤로 가기를 누르면 앱 밖이나 엉뚱한 화면으로 가요.

### ④ 로딩·빈 화면·오류 상태 (화면마다 3가지 모두)
- **95:** 홈, 지도, 목록, 상세, 검색(결과 없음 포함), 관심, 소식, MY 모두에 다음이 있어요.
  - 스켈레톤 로딩(레이아웃이 밀리지 않음, CLS < 0.1)
  - 빈 화면: 원인, 행동 버튼, 대안
  - 오류: 다시 시도 버튼과 문의 링크
  - 오프라인 배너
- **90:** 1개 화면만 상태가 빠져 있어요.
- **80:** 빈 화면은 있는데 오류나 오프라인 상태가 없어요.
- **70:** 빈 목록이나 흰 화면이 그대로 노출돼요.

### ⑤ 설정과 데이터 관리
- **95:** MY에 다음이 모두 있어요.
  - 내 조건 수정
  - 알림 종류별 켜고 끄기
  - 알림 권한 상태와 해제 방법 안내
  - 관심 구역과 조건 내보내기·공유
  - "내 데이터 모두 지우기"(확인 단계 있음, 실행 후 첫 실행 상태로 돌아감)
  - 앱 버전과 데이터 기준일
- **90:** 내보내기만 없어요.
- **80:** 초기화나 알림 해제를 찾기 어려워요(3단계 넘게 들어가야 해요).
- **70:** 설정 화면이 없어요.

### ⑥ 도움말과 법적 페이지
- **95:** FAQ(10개 이상, 검색 가능), 소개, 출처·계산 방법, 문의, 이용약관, 개인정보처리방침, 오픈소스·지도 저작권 표기가 있어요. 모두 앱 안에서 2탭 안에 열리고 모두 200이에요. 개인정보처리방침에는 알림·로컬 저장 항목이 적혀 있어요.
- **90:** FAQ가 얕아요.
- **80:** 일부가 웹 푸터에서만 접근돼요.
- **70:** 약관이나 개인정보처리방침 중 하나가 없어요.

### ⑦ 피드백 채널
- **95:** 상세 화면마다 "이 숫자가 틀렸어요" 신고 버튼이 있고 구역 ID가 자동으로 첨부돼요. 일반 문의 양식도 있어요. 접수하면 확인 메시지를 보여 주고, 답변을 받을 경로(이메일이나 알림)를 안내해요.
- **90:** 신고에 구역 ID가 자동 첨부되지 않아요.
- **80:** 문의 페이지 하나만 있어요.
- **70:** 문의할 방법이 외부 블로그뿐이에요.

### ⑧ 앱다운 느낌 (웹 티 없애기)
- **95:** 다음을 모두 지켜요.
  - standalone 표시, 스플래시와 아이콘(maskable)
  - theme-color가 헤더 색과 같음
  - 안전 영역(safe-area) inset 적용
  - 텍스트 선택·탭 하이라이트·길게 눌러 뜨는 메뉴를 UI에서 꺼 둠
  - 지도에서 당겨서 새로고침(pull-to-refresh)과 화면 튕김(overscroll) 방지, 목록에서는 의도한 새로고침
  - 시트를 끌 수 있고 손잡이가 있음
  - 화면 전환 애니메이션, 칩·슬라이더 햅틱(지원 기기)
  - 외부 링크에 ↗ 표시
  - 앱 화면에서 웹 푸터를 노출하지 않음
- **90:** 1~2개가 빠졌어요.
- **80:** 웹 푸터나 텍스트 선택 같은 웹 흔적이 3개 이상 남아 있어요.
- **70:** 브라우저 페이지처럼 느껴져요.

### ⑨ 설치
- **95:** manifest에 아이콘, 스크린샷, shortcuts(내 조건으로 보기, 관심 구역)가 있어요. 설치 권유는 사용자가 의미 있는 행동(관심 추가나 알림 켜기)을 한 뒤에만 띄우고, 닫으면 30일 동안 다시 띄우지 않아요. iOS에서는 "홈 화면에 추가" 안내를 따로 보여 줘요. 설치 후 `?src=app`이 측정돼요.
- **90:** iOS 안내가 없어요.
- **80:** 페이지를 열자마자 설치를 권해요.
- **70:** 설치할 수 없어요.
