## 2. 출처 표시 문구 (푸터나 about 끝에 그대로)

> 이 사이트는 서울특별시·국토교통부 등이 공개한 자료를 이용해요. 서울 열린데이터광장 자료(실거래가·전월세가·건축물대장·상권분석·역사마스터·대규모점포 인허가)는 공공누리 제1유형 조건에 따라 출처를 표시해요. 지도와 생활 인프라 위치는 © OpenStreetMap contributors(ODbL), © OpenMapTiles를 이용해요. 집핀은 서울시·국토교통부와 관계없는 개인 운영 사이트예요.

## 4. 남은 확인거리 (이용조건)

- **법원경매정보 자동 수집**: 법원경매정보 이용약관에 자동 수집 제한 조항이 있는지 아직 확인하지 않았어요. 심사 전에 약관을 읽고, 막혀 있으면 경매 블록을 '링크만'으로 낮추는 안을 권해요.
- **정보몽땅·도시계획포털·부동산정보광장**: 공공누리 표시가 없는 서울시 웹 서비스예요. 사실 정보만 쓰고 출처를 링크하고 있어요. 서울시 저작권 정책 페이지에서 조건을 한 번 확인해 두면 좋아요.
- **이마트 수서점**: 인허가 자료에 없어서 이번에 뺐어요(`tools/infra_mart.py`). 실제로 영업 중이면 OSM에서 다시 확인하고 넣어야 해요. 수서·일원 쪽 6구역의 마트 거리가 길어졌어요.
- **노선 그림(transitData.paths)**: 지도에 그리는 노선 선 모양이 어디서 왔는지 기록이 없어요. 역 좌표와는 따로예요. OSM 노선(ODbL)으로 다시 그리거나 출처를 확인해야 해요.
