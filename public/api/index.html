공개 데이터 API

사이트와 같은 자료, 같은 계산 엔진 결과를 JSON 파일로 공개해요. 로그인·키 없이 GET으로 읽으면 되고, 어떤 도메인에서든 불러올 수 있어요(CORS 허용). 실거래·고시·토지거래허가는 매일 새벽에 갱신돼요.

필요한 현금(need) 읽는 법

단위는 억원이고 무주택·84㎡·시세 상승 0%·비례율 100% 기본 가정이에요. gap.now는 전세를 끼고 지금 계약할 때 드는 돈(매수가 − 전세 + 취득세), gap.total은 입주까지 드는 돈이에요. cash.now는 대출을 끼고 지금 살 때, cash.total은 현금으로 입주까지예요. eligible이 false면 입주권·토지거래허가(실거주 의무) 등으로 그 방식으로는 살 수 없다는 뜻이라 개수에서 빼요.

// 내 현금 2억, 전세 끼고 살 수 있는 구역
const { items } = await (await fetch("https://jaegaebal.alwaysquestions.kr/api/v1/zones.json")).json();
const ok = items.filter(z => z.need.gap.eligible && z.need.gap.now != null && z.need.gap.now <= 2)
                .sort((a, b) => a.need.gap.now - b.need.gap.now);

이용 조건

원자료는 서울시·국토교통부 공공데이터(공공누리 1유형 등), 서울도시공간포털, 서울시 상권분석서비스, 서울부동산정보광장이에요. 쓰실 때 "집핀(jaegaebal.alwaysquestions.kr)"과 원자료 출처를 밝혀 주세요. 계산값은 공개 자료와 가정으로 낸 추정치이고 투자 권유가 아니에요. 파일 구조가 바뀌면 v2로 새로 열고 v1은 유지해요.
