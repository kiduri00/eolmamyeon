# 얼마면 재개발 (서울재개발.kr)

서울 재개발·재건축·모아타운 투자 계산기. 가진 현금과 매수 방식(전세 끼고 / 대출)을 넣으면 지금 살 수 있는 구역, 입주까지 필요한 돈, 입주권 여부와 막차 시점, 준공 확률을 보여 줍니다.

## 파일
- `index.html` 페이지와 구역 요약 데이터(임베디드 JSON)
- `data/geo.json` 서울·자치구 경계, 공식 정비구역 경계(구역 ID별)
- `data/tx.json` 구역 경계 안 빌라 매매·전세 실거래 목록
- `_headers` 정적 호스팅 캐시 설정 (data/는 파일 내용 해시를 URL에 붙여 불러옴)

## 자료
서울 열린데이터광장(부동산 실거래가·전월세가), 서울도시공간포털(정비구역 경계·연속지적), 정비사업 정보몽땅, 국토교통부 공공데이터. 지도 바탕은 OpenFreeMap(© OpenStreetMap 기여자). 모든 수익·분담금·입주 시점은 공개 자료로 만든 추정치이며 투자 권유가 아닙니다.
